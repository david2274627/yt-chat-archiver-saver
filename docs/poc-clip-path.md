# T1：clip-path PoC 測試

> 目的：驗證 SPEC 第 6 節方案 A 的關鍵前提。對 `ytd-live-chat-frame` 套 `clip-path` 後，被裁掉的上半部收到的點擊和滾輪，要穿透到下層的測試面板；底部露出的原生輸入框仍要能正常打字。
> 另外觀察：「完全不裁切」時原生彈窗的展開情形，以及 `$` 付款視窗開在聊天室內還是頁面中央。
> PoC 程式：`src/poc/clip-path-poc.js`、`src/poc/poc-panel.html/js`（T9 發版前移除）。

## 狀態
- 模擬頁面（非 YouTube）自動檢查：✅ Chrome 156.0.8078.75 下以 `elementFromPoint` 確認：裁切區域命中測試面板（div），未裁切區域命中 iframe 和「隱藏聊天室」列。
- **真實 YouTube 直播：⬜ 待使用者實測**（以下步驟）。擴充功能 iframe 下層、不裁切時的彈窗、付款視窗位置，都只能在真實環境驗證。

## PoC 行為
- 頁面左下角有藍色「PoC：開啟」按鈕（快速鍵 Alt+Shift+P）。
- 開啟後：
  - 在原生聊天室正後方放一個同位置、同尺寸、虛線框的**測試面板**（z-index 10），裡面有 200 個「測試列」按鈕。
  - 原生 `ytd-live-chat-frame` 移到上層（z-index 20）並套用 `clip-path`：從 iframe 底邊往上露出 **84px**，iframe 下方的「隱藏聊天室」列也一起露出。
  - 左下角出現 **PoC 控制盒**（不在面板內，所以不裁切時也按得到），內容如下：
    - 點擊／滾輪次數、最後點擊的列
    - 露出高度滑桿（40–240px）
    - 裁切對象：`ytd-live-chat-frame`（預設，SPEC 方案）或 `iframe#chatframe`
    - **下層類型**：`div`（藍色面板）或 `擴充功能 iframe`（橘色面板，等同正式版 `viewer.html?embed=1` 的情境）
    - **完全不裁切**（`clip-path: none`，原生聊天室仍在上層）
    - **目前可見彈窗／最近一次可見彈窗**：標示在「頁面」（top frame 的 `ytd-popup-container`）或「聊天室」（iframe 內），並顯示元素名稱和位置
- 再按一次（紅色「PoC：關閉」）完全還原。

## 測試前準備

> ⚠️ **絕對不要移除原本的擴充功能項目**：移除會連同 v2.6.0 的 IndexedDB 舊資料一起永久刪除。只能在該項目上按 🔄 重新載入。也**不要**對同一路徑再按「載入未封裝項目」。

0. **資料備份（必做）**
   1. `chrome://extensions` → 開啟「開發人員模式」→ 在原本的擴充功能項目上記下 **ID**。
   2. 完全關閉 Chrome。
   3. 把 `%LOCALAPPDATA%\Google\Chrome\User Data\Default\IndexedDB\chrome-extension_<ID>_0.indexeddb.leveldb`（以及同名的 `.indexeddb.blob`，如果有的話）複製到安全位置。使用其他 Chrome 設定檔時，把 `Default` 換成該設定檔資料夾名稱。
   4. 如果你已經把備份放在 repo 的 `bak/`：該資料夾已列入 `.gitignore`。建議再另存一份到 repo 以外的位置。
1. 重新開啟 Chrome → `chrome://extensions` → 在**原本的擴充功能項目**上按 🔄 重新載入（該路徑現在是 v3 程式碼）。
   - 檢查 T0：卡片上沒有紅色「錯誤」，名稱是「YT 加強版聊天室」，版本顯示 `3.0.0-dev`，圖示是藍綠色對話泡泡，ID 與第 0 步記下的相同。
2. 開一個**你能留言的直播**，確認右側原生聊天室是展開的。

## 測試步驟
1. 按左下角「PoC：開啟」。
2. **看畫面**：聊天室區域變成藍色虛線框的測試面板，底部只露出原生輸入框（約 84px）和「隱藏聊天室」列。
   - 如果露出的高度不剛好（露出太多訊息，或輸入框被切掉），用控制盒的「露出高度」滑桿調到剛好，**記下數字**。
3. **點擊穿透（div）**：點面板上半部任一「測試列」，該列變綠，控制盒「點擊」+1，「最後點擊」顯示 `div #編號`。
4. **滾輪穿透（div）**：游標停在面板上半部滾動滑鼠，列表要能捲動，「滾輪」數字會增加。
5. **輸入框**：點底部露出的原生輸入框，打幾個字，確認看得到文字（可以送出，也可以清掉不送）。
6. **下層切成「擴充功能 iframe」**：面板變成橘色。重複步驟 3、4，「最後點擊」應顯示 `iframe #編號`。
   - 如果橘色面板空白或沒出現：F12 → Console 截圖（看有沒有 `[ytcas-poc]` 或 `ERR_BLOCKED_BY_CLIENT` 之類的錯誤）。
7. **完全不裁切**：勾選「完全不裁切」。這時原生聊天室會蓋住整個面板，屬正常。接著：
   1. 點表符 😊：選單是否正常從底部向上展開？有沒有空白、重疊、位置錯亂？可以選一個表符嗎？
   2. 點 `$`：選單是否正常展開？
   3. 依序點進「超級留言」，走到**付款確認的前一步**就停（不要付款）。看控制盒的「目前可見彈窗／最近一次可見彈窗」：視窗是出現在「**聊天室**」還是「**頁面**」（整頁中央）？記下顯示的元素名稱。
   4. 取消付款流程，取消勾選「完全不裁切」。
8. （比較）裁切對象切成 `iframe#chatframe`，重複步驟 3–5，看結果是否一樣。
9. 切換劇院模式，面板是否仍與聊天室重疊。
10. 按「PoC：關閉」，原生聊天室要完全恢復原狀，控制盒也要消失。
